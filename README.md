# Launchset v1.4.5

Launchset v1.4.5는 **Source Focus & Sharpness** 품질 패치입니다.

## 핵심 변경
- URL Capture PNG-first
- 큰 캡처만 고품질 WebP fallback
- progressive downsampling
- `전체 보기` / `집중 보기`
- 집중 보기 source zoom
- 4 Direction의 제품 frame 비중 재조정
- Hero / Visual Pack output 규격 유지

## Runtime
- Node.js 24.x
- React 19
- Vite 7.1.3
- Tailwind CSS 4.3.3
- TypeScript 5.8.3

## Production Verification
동일한 `wavesstay.sixshop.site` URL을 v1.4.4와 v1.4.5에서 비교하여 작은 텍스트, 얇은 선, 브라우저 frame edge의 선명도와 제품 화면 가독성을 확인합니다.
